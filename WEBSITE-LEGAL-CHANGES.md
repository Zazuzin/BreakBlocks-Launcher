# Proposed BreakBlocks.com Legal Updates for the Launcher

These are focused additions for Sheepy to review and merge into the existing
BreakBlocks.com policies. They avoid replacing the website's unrelated terms.

## Terms of Service — add to the service description

> **BreakBlocks Launcher:** We provide an independent desktop launcher for
> installing and starting Minecraft: Java Edition, managing game instances and
> mods, signing in through Microsoft, checking for launcher updates, and
> connecting to optional BreakBlocks community services. BreakBlocks Launcher
> is not an official Minecraft product and is not approved by or associated with
> Mojang or Microsoft.

## Terms of Service — add a launcher section

> ### BreakBlocks Launcher
>
> You must own or otherwise have a legitimate right to use Minecraft: Java
> Edition and must follow the Minecraft EULA, Minecraft Usage Guidelines,
> Microsoft account terms, server rules, and third-party mod licences.
>
> Microsoft sign-in checks Minecraft entitlement. Offline profiles are for
> legitimate local or offline use and may not be used to bypass ownership,
> authentication, bans, parental controls, or service restrictions. The
> launcher must verify ownership through a Microsoft account before an Offline
> profile can be added or launched.
>
> Minecraft, Java runtimes, loaders, mods, and updates are supplied by their
> respective providers and are not part of the BreakBlocks Launcher licence.
> Compatibility information is provided as-is. Users should back up important
> worlds and are responsible for deciding whether third-party content is safe
> and permitted on a server.
>
> Automatic update checks can be disabled. The launcher asks before installing
> an update and verifies the package against release metadata and a SHA-256
> digest.

## Privacy Policy — add to information stored locally

> The BreakBlocks Launcher stores Microsoft/Minecraft profile details and
> authentication tokens, Offline profile details, instance configuration,
> installed-mod information, playtime, preferences, downloaded content, and
> logs on the user's device. This local information is not automatically sent
> to BreakBlocks. Users can remove profiles and instances in the launcher and
> can open the data folder from Settings.

## Privacy Policy — add to third-party processing

> When requested by the user, the launcher connects directly to Microsoft
> identity, Xbox Live, Minecraft Services, Mojang download services, GitHub,
> Modrinth, Adoptium, Fabric, Quilt, Forge, NeoForge, Meteor, and configured mod
> sources. Those providers receive normal network/request information and apply
> their own privacy notices. Microsoft authentication tokens are sent only to
> Microsoft/Xbox/Minecraft endpoints for authentication, entitlement, profile,
> and token-refresh operations; they are not sent to BreakBlocks.
>
> The launcher currently contains no advertising, analytics, tracking SDK, or
> automatic crash-report upload. Launcher update checks contact GitHub Releases.
> Logs remain local unless a user chooses to send them for support.

## Privacy Policy — add for launcher web chat

> When a user opens Chat, the launcher displays
> `https://irc.breakblocks.com/#/connect` in an embedded browser. The website may
> store cookies and other site data in a dedicated local browser profile so the
> user can remain signed in. The chat operator receives the normal web request
> information and any account, channel, message, or protocol information the
> user supplies through the service. State here who operates the service, what
> cookies or connection/message data are retained, the purposes and lawful
> basis, the retention period, moderation rules, minimum age, data recipients,
> international-transfer arrangements, and how a user can exercise privacy
> rights. The website's logout or session-management controls govern removal of
> the active chat session.
